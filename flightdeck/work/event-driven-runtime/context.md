# 实施上下文

用户希望工作流可同时保持主流程与周期监测，监测触发后暂停主任务、处理完继续或退出。暂停必须保留剩余等待时间和控制帧，不能取消后重跑整个节点。持续移动远处按住 W、接近减速，实时位置由独立来源节点提供。

保留 Source → Catalog → Program → Executor 唯一路径、类型化数据/执行/错误通道、Configured Target 配置直驱和 Run 资源所有权。新并发不引入逐操作授权、身份扫描或安全包装层。副作用提交和输入交接需要确认，不承诺任意 Go/脚本调用随时可暂停。

用户明确未发布：不保留旧执行器或兼容兜底。待新合同定稿后提供一次性本地数据迁移工具，备份后转换并重新编译。已有外部已发布合同按实际消费者协调，不假定可改写发布事实。

唯一执行器已交付显式控制帧与 Scope 任务树、Activation 输出快照隔离、有界期限等待及异步 adapter/pull 续接；共享图状态由调度线程单写入。周期监测与主任务共同推进，处理分支可打断并恢复主任务；嵌套暂停保留控制帧、冻结活动时钟和剩余等待，退出区域排空其等待及清理，不执行被取消的后继。RunRecord/Summary v2 使用有界尾部和验证 checkpoint，完整历史保留在 SQLite；一次性用户资料迁移已完成；真实游戏验收独立记录。

调试任务树复用现有深色 Nuxt UI 面板、按钮与语义状态徽标：每行呈现角色（root/main/tick/handler）、节点和状态，按层级缩进；多任务时默认展开，可整体折叠。节点点击携带精确 graphPath 与 nodeId 定位，不能只凭节点 ID 猜测所属图；任务状态发布按 10 Hz 节流，并跳过未变化的任务快照。桌面与紧凑视图截图为 `.task/event-runtime/tasks-desktop.png`、`.task/event-runtime/tasks-compact.png`，UI 审查无 material fixes，WebView 合成测试总计 9.3 秒；这些合成证据不代表新一轮真实游戏验收。

Run 成功不等于每个子任务都成功：显式退出区域可取消其未完成等待。Journal 继续拒绝取消动作对应成功 attempt、未关闭 attempt 和未处理失败；允许已正确关闭的取消子任务存在于成功 Run。取消清理中的存储错误必须保留，不能因同时携带 context.Canceled 而被吞掉。

用户已授权 checkpoint commit 和实现，未授权 push、生产部署或改写历史。面板按钮动作和插件热加载保持此前暂缓决策，不混入本任务。

插件 companion 按编译产物引用的 Configured Target 在每个 Run 入队后准备，使用同次 Run 的不可变目标配置；失败也留下持久 Run，活动运行占用服务所有权。扩展面板可独立显示或隐藏，不承担工作流启动前置步骤。首次位置采样等待节点超时，后续新样本必须来源序号/时间前进，不能仅靠状态槽版本增加。
