# 公开用户文档

公开文档由独立的 [yottaapp/docs](https://github.com/yottaapp/docs) 仓库维护，本地目录为生态根目录下的 docs 仓库。

- [用户指南](https://github.com/yottaapp/docs/blob/main/content/index.md)：中英文正文及截图。
- [文档维护与发布](https://github.com/yottaapp/docs/blob/main/CONTRIBUTING.md)：一键打包、月离文档导入和 GitHub Actions。

原 docs/user-guide/ 以及中间整理目录 user-docs/ 的内容已迁入文档仓库的 content/。本产品仓只保留与源码版本一起维护的开发说明；不读取相邻文档源码，也不再重复打包 docs.zip。文档包与产品版本的对应关系由文档仓库的 release.json 记录。
