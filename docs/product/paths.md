# 路径工具与节点

路径是带坐标参照的有序点列。它可以由定位插件录制、手动打点、手动输入或导入生成，
再由同一组节点读取和执行。点数没有固定的产品上限；单份内容使用宿主的 16 MiB 数据预算。
路径工具保留绕行点，不会根据没有障碍信息的直线替换路线。

## 录制和编辑

左侧是工具栏与画布，下方是途经点列表；右侧集中编辑定位源、选中点和路径信息。
右侧内容独立滚动，保存按钮固定在底部。画布支持滚轮缩放、右键拖动或空格加左键拖动。
窄宽度下仅 X/Y 字段按容器宽度纵向排列，检查器仍在右侧，不恢复上下堆叠的路径表单。

1. 资源库左侧“路径”（与键鼠宏、精准轨迹、视觉模板并列）→ 新建路径，在右侧资源信息填写名称、分类和标签。
2. 启用定位插件，在定位源中选择已配置的网络连接。列表显示连接名称，选择后自动使用该连接的定位采样地址。
   打点或开始录制时，宿主会启动该插件配置的采集服务并等待就绪，无需先打开扩展面板；面板只负责显示。
   采集服务启动后最多等待 10 秒获取新鲜坐标；等待中不写入过期点，超时会明确提示，录制可随时暂停。
   没有可选连接时，可通过配置入口添加；需要自定义地址时，展开高级手动输入，填写完整采样 URL。
3. 点击当前位置打点，或保持路径编辑器打开，切回游戏按全局打点快捷键（默认 F6）。
   快捷键中心的“录制”分组提供“路径：当前位置打点”；编辑器显示当前绑定并提供修改入口。
   只有当前打开的编辑器响应打点事件，退出编辑器不会注销绑定。
4. 连续录制按采样间距保留点，后端负责采样时钟。暂停、定位丢失或过期会保留已录点位；
   点击继续录制表示从当前末点继续。“结束录制”在录制或暂停时均可用：结束本次录制会话，保留全部已录点，
   返回编辑状态，再按需保存；它不会丢弃点或自动保存。坐标参照或定位会话改变时不会继续连接，需确认稳定参照后重开，或新建路径。
5. 点列支持命名、XY/可选高度编辑、插入、删除、前后排序、更新为当前位置、反转和撤销。
   预览不依赖底图；X/Y 轨迹不能代替道路或楼层地图。
6. 点击右侧底部保存，将路径内容及名称、分类、标签保存到共享资源库；名称、分类和标签可在资源库中继续管理。
   保存后可返回路径资源列表，双击或选择“编辑路径”重新打开；列表支持搜索、分类标签、筛选和批量管理。
   导入/导出使用路径 JSON 文件。名称属于素材库，工作流绑定固定内容。
   修改库内路径不会自动更换已有工作流的引用，需在节点中重新选择。

在快捷键中心修改或清空打点快捷键后，设置会保留到下次启动。只有打开路径编辑器并配置定位源后，按键才会追加路径点。

手动路径先配置坐标参照，再添加点。局部路径相对固定原点，不是相对上一个点。
未知高度用“未包含高度”，不能填零冒充未知。仅会话有效或需要对齐的定位源，不能在重开路径时假定恢复了旧原点。

## 在工作流中使用

工作流左侧选择“路径”，可用以下方式放入工作流：

- 将路径拖入画布，在落点创建并绑定“沿保存路径移动”，不会覆盖当前选中节点。
- 点击绿色“使用”，选择“沿保存路径移动”或“读取路径”。这些操作添加节点，不会立即运行移动。
- 点击路径名称：若当前选中节点有兼容的路径资源输入，直接绑定；否则创建并绑定默认的“沿保存路径移动”。

其他资源采用相同交互：模板拖拽默认添加点击模板节点，绿色“使用”可选择点击、等待出现或等待消失；
键鼠宏和精准轨迹默认添加对应的播放节点。只有一种操作时，“使用”直接添加节点，不再展开菜单。
也可手动添加“沿保存路径移动”，在检查器选择保存资源。

路径也是变量类型，可在变量面板中创建或更改类型。类型选择带有与变量列表一致的色点；
字符串、布尔、数字、整数、JSON、路径等常用类型排在前面，全部可选类型仍可搜索。
需要动态构建或变换点列时，使用“读取路径”与路径数据节点，再把路径结果连接到“沿路径移动”；
也可以用路径变量保存并传递结果。

为移动节点选择自动化窗口目标，并配置持续更新的定位源。定位源字段只列出字符串变量，
附有采样内容说明；没有兼容变量时会显示接入引导。路径变量存放路线，定位字符串变量存放实时观测，两者用途不同。

1. 展开定位源接入，选择已配置的网络连接。这里使用已配置连接；手填采样 URL 是路径录制编辑器中的高级选项。
2. 点击接入后会先检查一次采样；失败原因显示在字段附近。成功后自动添加定时采样节点、空字符串变量和初值为真的活动布尔变量，并为移动节点绑定定位字符串变量。名称冲突时自动使用可用名称，整次接入可以一次撤销。
3. 工作流运行时固定每 100 ms 更新一次定位字符串。移动节点结束后，活动状态关闭，采样任务在下一次检查状态时停止。该间隔属于生成的工作流采样，不是录制点的采样间距。

已有采样流程时也可直接选择其字符串变量。手动接入需把采样接口返回的完整定位 JSON 写入字符串变量，
不能使用旧“解析实时位置”的位置结果代替。位置和镜头朝向必须持续更新；含高度的点还需要高度观测，已知地图和楼层须匹配。

起终点索引从 0 开始，end=-1 表示末点，不自动跳到离角色最近的点。每点最长时间独立计算。
默认使用 W 前进，鼠标转向采用自动化目标的转向校准。路径不会自动跳跃、爬楼或绕过未录制的障碍物；
经过楼梯、转角或坡道时保留足够的途经点。

“对齐局部路径”指定目标世界参照、原点和逆时针旋转角，将局部点变为世界点；单位必须一致。
其他数据节点包括构建路径、获取点、截取、反转和拼接。拼接要求参照一致，且不能重复包含同一个途经点。

## 结果和恢复

移动节点提供当前途经点、最后到达点的位置序号、最终 XY 和剩余距离。未到达任何点时，最后到达点序号为 -1。
时间线点号从 1 开始显示，0 表示尚未到达。

| 结果 | 恢复方式 |
| --- | --- |
| 到达 | 沿所选点列走到终点 |
| 超时 | 检查当前点距离和每点最长时间，从失败点重试 |
| 无法前进 | 恢复次数耗尽或未连接恢复分支；检查时间线中的前进／镜头无响应原因 |
| 坐标不可用 | 恢复位置、镜头朝向和所需高度采集 |
| 参照不匹配 | 核对坐标系、单位、地图/楼层和定位会话 |
| 高度不匹配 | 添加经过楼梯/坡道的点；不要把另一楼层当成已到达 |

退出、取消、超时和定位失败都会释放持有的按键。定位算法、采样误差、游戏更新和未知地图信息仍决定实际定位质量；
提供坐标不等于提供障碍地图，也不等于自动寻路。

当前录制需要提供统一位置源的插件。地图/小地图图像定位尚未实现；游戏底图和扩展面板地图组件处于研究阶段，尚未提供。没有位置源时可以手动编制路径，但仍需匹配的实时定位才能执行。

本轮界面交互通过模拟后端的浏览器预览核对，覆盖资源使用、路径拖拽、定位源选择、类型颜色及暂停、结束、保存。
自动生成的采样工作流另有 CLI 编译验证记录；编译通过不代表已在游戏中执行。连续跟随、途中动作与恢复分支另有合成定位源和输入夹具的执行测试；真实游戏路线及游戏内全局快捷键仍需现场验证。

## 长路径的直接执行

保存的路径可直接在“沿保存路径移动”中选择。该节点一次读取完整的已保存路线，随后连续跟随路线，无需拆成许多小路径。已有自动化执行测试覆盖 20,000 点、超过 1 MiB 的路线及指定起终点；这不代表真实游戏路线实测。

“读取路径”用于需要在数据节点中变换的路线，遵守通用节点数据线1MiB容量；超出时会明确提示改用“沿保存路径移动”。路径文件读写预算为16MiB，没有固定的途经点数量限制。长路线的人工编辑、反转和点位调整仍可直接在路径工具完成。

## 连续跟随与途中动作

普通采样点描述路线形状，不要求逐点停车对准。跟随器在当前连续路段选择前瞻目标，直路保持前进，缓弯边走边转，急弯和终点才停下调整。闭环起终点相近不会直接结束；交叉路线按既定顺序推进，不全局跳到最近一段。没有障碍地图时不承诺自动绕障。

两个移动节点都提供三个任务分支：

- **移动中**：按动作间隔触发，可连接按键 F、识图后按键或子图。前一次未完成时合并后续触发，不堆积并发动作。每次事件的数据输出是该次进度快照；长循环内部不会自动刷新这份快照，持续检测时优先让一次分支完成后等待下一次触发。
- **到达标记**：路径编辑器给点填写名称后成为标记。按顺序经过时触发一次，输出名称和点 ID，可接条件或子图；普通无名称点不会触发。可选边走边执行或暂停移动后执行，暂停模式执行完自动接续路线。
- **尝试恢复**：连接自定义按键或子图，例如 A 保持 3000ms，然后 W＋空格。开始前释放导航按键，结束后获取新定位并从中断进度继续。默认同处最多尝试 2 次，可设 0 关闭；只有继续跟随后实质进度增长才允许新的恢复预算。

需要一段路持续冲刺时，在“移动中”按当前点索引筛选后执行有限时长 Shift 按键；下一次触发继续判断路段。W＋空格/F/Shift 可和导航前进组合，同一按键的一个持有者结束不会释放另一个持有者。转镜头或鼠标操作应采用暂停标记或恢复分支，避免两个任务争夺镜头。

移动中分支在到达、失败和取消时停止；到达时已排队的标记动作会完成。未连接恢复分支或次数耗尽后，才触发原有“无法前进”输出。定位不可用、参照变化和终点高度不匹配分别处理，不盲目执行物理脱困。

多个“Run 开始”在同一次运行中各触发一次，不表达先后依赖。自动定位接入有独立采样入口；若必须先激活窗口再开始某流程，用执行连线表达顺序。途中和恢复分支不会被自动接入逻辑误接为停止定位采样的条件。



## 录制点与平稳转向

原始路径资源保持完整。执行时自动整理前瞻使用的点列，合并偏差范围内的冗余点；保留必要转角、命名标记和参照相关边界。闭环保留交汇位置和有序锚点，控制器按连续路程取前方目标，不能直接连接起终点跳过一圈。界面显示的原始点数不会因此减少，标记ID、点索引和恢复进度仍对应录制点。

路径跟随使用近期速度选择前瞻距离，对小幅朝向误差设置进入/退出不同阈值，避免定位噪声触发来回纠偏；移动中的转向有角速度和角加速度限制。路径专用转向按短时间段发送鼠标角度增量，不再统一套用单点移动的150ms转动加50ms等待。单点“移动到坐标”不切换这套路径转向。

路径进度记录补充当前位置、前瞻目标、朝向误差、速度与采样年龄，供运行导出定位问题。坐标仍按定位源单位解释，不自动当作米。没有障碍地图时，点列整理不等于自动绕障。

路径控制使用定位源的实际采样时间估计当前朝向与位置，原始观测仍用于确认进度和到达。短暂观测延迟期间，路径任务的唯一输入写入器持续发送转向增量；新方向替换旧要求，不排队积压。起步或急转需要较大角度时快速对齐，缓弯则持续前进并微调。暂停、取消和定位过期会结束转向；恢复时重新获取观测。以上只作用于路径跟随节点。


## 路径列表与录制窗口

工作流左侧“路径”复用资源库列表：可以搜索、按分类/标签筛选和排序，勾选单项或整页，批量修改分类/标签或删除。部分删除失败时保留失败项勾选并显示成功/失败数量。删除资源库条目不会改写工作流已经固定引用的路径内容。

从路径列表或资源库点击“新建路径”/编辑，打开独立路径录制窗口，主工作流画布保持原位置。窗口默认置顶，标题栏图钉可以取消置顶；支持拖动和调整大小。重复打开会复用这个窗口，切换路线或关闭时保护未保存内容。暂停保留录制会话，结束录制后可以编辑和保存；关闭窗口停止采样。保存和删除会同步更新主窗口资源列表。F6仍由快捷键中心管理。
