## Platform

web

Vue interface inside a Windows Wails desktop application. This record captures the established product and the extension-panel direction confirmed by the user; it does not replace repository contracts.

## Users and purpose

Users run desktop automation workflows and combine separately installed plugins. Creators author typed workflows and plugin contributions. The confirmed extension-panel job is to display live coordinates, logs, durations and controls in a larger floating window, with registered tabs/components and bidirectional interaction.

## Operating context

An existing floating launcher starts workflows. Independent NTE combat and position plugins provide live data through local companion services. Panels must remain understandable while a game or another desktop app is in use.

## Capabilities and constraints

Definitions, sessions and windows are separate. Preserve user workflows, plugin independence and public SDK boundaries. Installation expresses user intent; normal operation must not add repeated technical authorization. The accepted roadmap includes standard and custom components, plugin presets and user composition, and workflow interaction.
